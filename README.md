# 📱 Contact CRUD - Node.js + Express.js + MVC

Project belajar membuat aplikasi **Contact CRUD API** menggunakan:

- Node.js
- Express.js
- MVC Architecture
- REST API
- JSON sebagai database sederhana
- ES Module (`import/export`)
- `fs` untuk membaca dan menulis file
- `console.log()` untuk testing dan debugging
